# One-Liner Laugh Lab — The Vacuum's Defense

A robot vacuum's excuse after eating a sock, as one short funny line.

## The line

> Per section 4 of my user manual, anything on the floor is legally floor. The sock was on the floor. Case closed.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (112 characters, one line, deterministic — the same output on every run).
